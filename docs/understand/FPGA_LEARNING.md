# FPGA 学习

> 写作约束：[skills/regulation.md](../../../skills/regulation.md)。本文记录频率、边界和 PDS 的经验，不把工具估计写成板上结果。

## 1. 为什么加寄存器边界

长组合路径通常跨 Core、fabric、DDR 桥。把请求、响应、IRQ 各寄存一次可以切断
同拍穿透，但每笔事务会增加等待。第四轮把 TCM 从接近 1 拍变成约 4–6 拍，
SoC TCM 从 2.897145 降到 0.844686。频率收益和周期代价必须同时记录。

## 3. I2 对照与当前 P0

2026-10-20，RV32 i1/full/local0/cache_block1/dma_wide1/dma_block1：

- 同域 Fmax 65.4279 MHz，125 MHz WNS −7.284 ns。
- 物理 LUT/FF 24888/20140，DRM36K 34，APM 4，0 latch，0 未布通。
- 前 100 条 SoC setup 路径全部从 `reset_sync_q[1]` 出发。
- 最差路径：reset → `retire_gpr_query` → `ex_operand_register` → DSP 乘法。
- DDR PHY 跨域 −0.061 ns；35 输入、73 输出缺 IO 延迟约束。

该轮复位网是首要物理问题。后续修正后，旧 i1 标准布局在 85 MHz 约束下得到
92.3306 MHz、WNS +0.934 ns、0 未布通。该结果不适用于新 scoreboard Core。

当前 P0 使用 ROB16、IQ8、LQ4/SQ4 和真实双数据口。`fdb3ffb` 将 ROB 完成和
退休分拍；RV32 综合最差路径为 19 级、13.177 ns，经过完成仲裁与 IQ 操作数捕获。
该历史检查点布线已中断。head `14897f1` 的 r11b 完整标准 PDS 为 81.5878 MHz，
未过 85 MHz；CMP `2b49c77` 的 r12 提高到 87.8837 MHz，85 MHz WNS +0.386 ns、
TNS 0、零未布通，全部已报告 STA 无失败。最差路径已转到 IQ 读指针至 DSP。
ISS `85ab1ca` 以两项寄存发射包切开该路径，同时用操作数旁路、提前分支解析和
Load 返回提示减少等待，ALU/Load/DSP 为 8/10/10 级。完整双宽回归和八次固定镜像
重放通过，M0/M1 对 CMP 提升为 RV32 9.84%/8.61%、RV64 8.59%/7.75%；r13 完整标准 PDS 为 82.8726 MHz、WNS −0.302 ns、86 个 slow setup
失败端点、零未布通，频率验收失败。完成预选 `180f6fc` 保持八次重放周期与全部

其余 11 类 STA 零失败。最差路径转为 LSQ Store 覆盖/请求选择，经 Load 格式化和

## 4. PDS 流程

1. WSL 生成 loader、准备工程、复制 IP 和固件。
2. Windows PDS 编译/综合。
3. 检查 TCM INIT 和 staged 文件哈希。
4. `dev_map`、标准 `place`、`route`、`route_optimize`、`report_timing`。
5. 保存 manifest、哈希、资源、WNS、最差路径、未布通网络。

每次新目录放 `$PDS_WORK_ROOT\work\`，`reference/` 只读。常规 place 曾在 EP_DL
大块分配失败，历史快速布局仅作对照。本轮只使用标准模式；r8 已越过 EP_DL。
每阶段前释放自有生成文件的可丢弃缓存，Windows 物理可用量与提交余量分别至少
6 GiB；WSL 缓存曾使 Windows 余量降到 0.806/1.364 GiB，释放后恢复为
10.927/8.771 GiB。不得与仿真/编译并发；分页、无关进程与烧板操作须用户明确授权。

## 5. 时钟约束、实际 IP 与板级验收

当前 Core、SoC、TCM、Cache、MMIO 与 AXI 用户侧共用 DDR IP 的 125 MHz 时钟，
DDR PHY 的高速时钟另列。85 MHz 是 P0 的 STA 验收目标，尚未重新生成相应 IP，
没有板上频率测量。`DIV_IMPL=1` 选择 SRT 除法器，不能理解成时钟分频。
当前先优化整体周期与主频；整体提频受阻后再评审分频及 CDC。板级验收还需要：

1. 按最终运行频率生成 IP，核对 PLL、DDR、UART 和软件时基。
2. 若后续采用多个时钟域，补齐 CDC、复位和时基测试。
3. 补齐外部 IO 延迟约束和 DDR PHY 跨域。
4. 真实 DDR 校准、UART、ILA、十秒 CoreMark 和功耗。

## 6. 资源与 profile

I2 物理 FF 20140，其中 DMA 双 128B 缓冲、块桥读写缓冲、full 外设占比大。
CoreMark 用不到 DMA 块口。当前 P0 保持完整 `full` 外设与 DDR 硬件，
M0 Core-only 与 M1 完整 SoC-TCM 分开测量。后续若评审资源裁剪，可比较：

- perf：i1、local TCM、I$/D$ 块口、lite 外设、DMA 关闭。
- full：i2、DMA 块口、full 外设。

i1 时用 generate 完全裁掉第二 ALU、额外 RF 口和第二完成口，避免板级候选承担
未使用的双发射面积。

## 7. 还不能说的事
